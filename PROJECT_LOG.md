## 2. Defect fixed: two INVESTIGATING relationships lost on load

Root cause: `scripts/generate_data.py` chose a random lead officer per crime and then appended hard-coded support
officers. For CR004 (B1215) and CR014 (B1210) the random lead *was* the support officer, so `rel_investigating.csv`
contained the same (officer, crime) pair twice. The loader `MERGE`s, so the two rows collapsed into one relationship and
the second row overwrote `lead_investigator` with `false` - CR004 and CR014 ended up with **no lead investigator**.

Fix: when the support officer equals the lead, pick the next officer of the same department (no extra random draws,
so the rest of the dataset is unchanged) and assert that all 35 pairs are distinct. Only 2 CSV rows changed;
`results.json` did not change (the Python reference had computed the intended data all along).

## 3. Backend additions

Decisions (kept inside the existing Express app, no new services):

* **Authentication** - `api/src/auth.js`, Node's built-in `crypto` only (no new dependency).
  Passwords: scrypt (N=2^14, r=8, p=1, 16-byte random salt), stored as `scrypt$salt$hash` on `:User` nodes.
  Tokens: HMAC-SHA256 signed `{sub, role, exp}`, 8 h lifetime, sent as `Authorization: Bearer`.
  Unknown users cost the same scrypt work (no timing oracle); 10 failed logins per ip+username -> 429 for 15 min.
  `:User` is an application label, never connected to the investigation graph; `user_username_unique` constraint added.
  The previous optional `x-api-key` switch was removed (superseded).
* **Authorisation** - one policy in `authorize()`: GET -> viewer, POST/PATCH -> investigator, DELETE -> admin;
  user management admin-only. Self-registration creates viewers; first admin comes from `ADMIN_USERNAME/ADMIN_PASSWORD`.
* **Graph endpoints** - `api/src/routes/graph.js`: overview with label/type filters, neighbourhood (depth 1-2),
  shortest path (KNOWS-only or any relationship) returning nodes + ordered edges, 404 for unknown ids, `found:false` for no path.
* **GDS** - `db/07_gds.cypher` + `api/src/routes/gds.js`: Cypher projection of Suspect/KNOWS (undirected, weight = strength),
  Louvain (weighted), PageRank, Betweenness; unique projection name per request, always dropped; 503 when the plugin is absent.
* **Entity search** - `GET /api/:entity?q=` case-insensitive match on any property.
* **Errors** - 500 responses no longer include internal error text; 503 no longer echoes driver messages.
* **Reset** - `setup_db.py --reset` and `99_reset.cypher` now keep `:User` accounts.

## 4. Web interface (`web/`)
